# Terraform playground

## About

A collection of Terraform examples I found useful and want to share.

- docker-demo: local demo of spinning up a Docker container with Terraform
- aws-infra: Create starter infrastructure tutorial for Terraform on AWS, a EC2 instance.
- aws-ec2-ssh: Creating an EC2 instance with SSH support.

## Security notes

All of the above examples aren't production grade as-is. Please remember to not commit keys, restrict incoming addresses with subnets, carefully store SSH keys, decide what params work best for you, and etc.
